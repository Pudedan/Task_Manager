# Personal Task Manager

**Project Code:** WST21-PM-2026-SF

**Student Name:** Daniel Kim A. Tudtud

**Course & Year:** BSIT - 2nd Year

**Database Used:** MySQL

## Features

* Add Task
* View Tasks
* Edit Task
* Delete Task
* Update Status
  * Pending
  * Completed
* Set Task Priority
* View Task Priority
* Task Due Dates
* Task Descriptions
* Task Search and Filtering
* Task Status Filtering
* Responsive User Interface
* Dashboard Task Management
* Action Confirmation
  * Delete Confirmation
